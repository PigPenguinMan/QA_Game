# QA_Game - 슬라임 사냥 (원본 버전)

QA 테스트케이스,버그리포트 작성 연습을 위해 만든 턴제 전투 웹게임입니다.
의도적으로 결함이 포함된 **원본 버전**을 테스트하며 결함을 찾고 문서화했습니다.

## 게임 규칙

- 시작 상태: HP 100, MP 30, 골드 10, 포션 3개
- 공격(10~15 피해), 스킬(MP 10 소모, 25 피해), 방어(피해 감소), 포션(HP +30)
- 승리 시 골드 +20, EXP +30, EXP 100 도달 시 레벨업
- 상점에서 15골드로 포션 구매

## 테스트 범위

| 구분 | 내용 |
|---|---|
| 기능 테스트 | 공격, 스킬, 방어, 포션, 상점, 전투 종료, 성장, 재시작 |
| 경계값 | 골드 정확히 15G, HP 최대치에서 포션 사용, 포션 0개, MP 0 |
| 상태 조합 | 방어 후 새 전투, 승리 직후 행동, 패배 후 재시작 |
